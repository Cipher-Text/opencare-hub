User Functionality Matrix

Feature access in Open Care is controlled through config-driven feature flags and role-based access control (RBAC) using Keycloak.

  • ✅ = Available in Free tier
  • 💎 = Planned for the paid plans (Plus and Pro)
  • The tables below show the intended plan design, not what is built. See "What is built today" first.
  • Availability may change as the platform evolves.

This matrix helps users, partners, and institutions clearly understand who can do what inside Open Care.

Roles Covered

  • Patient
  • Doctor
  • Nurse
  • Hospital Admin
  • Diagnostic Center Admin
  • Social Organization Admin
  • Association Admin
  • System Admin (Internal)

Important Notes

  • Free access ensures basic healthcare discovery and participation.
